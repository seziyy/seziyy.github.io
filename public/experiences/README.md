# Experience Images

Place images for each experience in these folders:

- `/public/experiences/buildermare/`
- `/public/experiences/san-tsg/`
- `/public/experiences/businessup/`
- `/public/experiences/egebarkod/`

Recommended naming:

- `1.jpg`
- `2.jpg`
- `3.jpg`

Current experience page expects these file names in each folder.
You can use `.jpg`, `.jpeg`, `.png`, or `.webp` if you also update the file extension in `app/experiences/page.tsx`.
